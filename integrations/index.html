FAQ

Questions teams ask first.

Which agent platforms work with TryVox?+

Vapi, Retell, ElevenLabs, LiveKit and Bolna, plus any standards-based SIP stack.

Do I need to configure SIP for agent platforms?+

No. Binding a number to an agent needs no deployment or SIP configuration.

Can agents call out through TryVox?+

Outbound calls from agents are still in progress. Inbound calls work today.
