FAQ
Questions teams ask first.
How does authentication work?+
HTTP Basic auth. Your Auth ID is the username and your Auth Token is the password.
Where do callbacks go?+
To the URLs you set on each call, such as answer_url, ring_url, hangup_url and status_callback_url.
Are webhooks signed?+
Yes. Set a webhook secret and TryVox signs callback requests with it.
Where is the full reference?+
At docs.tryvox.io.
