FAQ
Questions teams ask first.
Something else? Talk to the team.
Which AI voice agent platforms work with TryVox?+
Vapi, Retell, ElevenLabs, LiveKit and Bolna.
Do I need to configure SIP to connect my agent?+
No. Binding a number to an agent needs no deployment or SIP configuration.
Can my agent make outbound calls through TryVox?+
Inbound calls to a bound number go straight to the agent. Outbound calls from agents are still in progress, so don't rely on them for production yet.
Can one number go to two agents?+
No. A number binds to one agent at a time.
Should I also set the number as inbound in my provider?+
No. Doing both can make calls conflict. Let TryVox route the number to the agent.
