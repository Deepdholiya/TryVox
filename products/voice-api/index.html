VoxML

Build the call flow in VoxML.

When a call is answered, TryVox asks your answer_url what to do. Reply with VoxML verbs and TryVox runs them on the call.

  • Stream to send live audio to your agent

FAQ
Questions teams ask first.
Something else? Talk to the team.
How do I authenticate with the TryVox Voice API?+
HTTP Basic auth. Your Auth ID is the username and your Auth Token is the password. Both are in the dashboard.
What does answer_url need to return?+
VoxML. TryVox calls answer_url when the call is answered and runs the VoxML verbs you return.
Can I place outbound calls in bulk?+
Yes. The same calls endpoint accepts a list of calls.
Can I record calls?+
Yes. Record calls and fetch recordings through the API.
Is answering machine detection available?+
Not yet. The parameter is accepted but has no effect today, so don't rely on it.
